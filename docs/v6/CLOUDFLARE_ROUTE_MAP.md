## Phase 5 addition

The generated foundation inventory below is preserved. Phase 5 additionally supports `GET /api/admin/affiliate/revenue` when `SANDEAL_MONEY_ENGINE_ENABLED=true`: ADMIN_DYNAMIC, D1-only, Worker required, no-store, private data, existing configured Basic authentication required. Queries require scope, scopeId, currency, from and to, with a maximum 31-day indexed range. `PLATFORM` scope keys include the provider, for example `accesstrade:shopee`; fixture balances are never returned by the production-default route. Unsupported live conversion/commission sync remains explicit in the response.

With the same opt-in flag, `/go/[productId]` uses the money router and persists a minimal D1 click before redirecting. Publication, provider health, provider/platform provenance, freshness and exact destination allowlisting are enforced. Caller-supplied destinations are rejected. The flag remains false in local configuration; the existing Phase 4 redirect is unchanged by default. No deployment or audience change is implied.
